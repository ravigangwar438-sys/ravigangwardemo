# AI Traffic Management & Stolen Vehicle Tracking System

This repository contains the database structure, design documentation, and ER diagram for the AI Traffic Management System.

## Contents
* `schema.sql`: Complete PostgreSQL schema script for creating tables.
* `DATABASE_DESIGN.md`: Detailed documentation of entities, columns, and relationships.
* `er DAIGRAM`: Visual Entity-Relationship Diagram.

## Database Connection (Render Cloud PostgreSQL)
Backend API developers can connect to the hosted PostgreSQL instance using the provided connection string in environment configuration.
